Automatic range queries use a bounded rational-quadratic interval rule before general elimination and calculus. It preserves owned endpoint values, disconnected components and source holes; see [specialized rules and benchmarks](guides/fast-rules.md).

Bounded rational sign charts and guarded elementary comparisons serve scalar sign and Jacobian queries. Supported coupled C2 expressions on rational boxes can use outward Hessian diagonal-dominance bounds with a replayable strong-curvature modulus. Structural quadratic-exponential Hessian bounds and exact interior polynomial counterexamples supplement these bounds. Scalar Jacobians can reuse finite trigonometric zero sets. Relative seam continuity and bounded entire square-root cancellations also expose independently replayable records. See [bounded proofs](guides/bounded-proofs.md) for exact scope and limitations. These sufficient rules retain source restrictions and decline unsupported or inconclusive inputs.

## Remaining capability boundaries

General transcendental parameter geometry, arbitrary analytic gcd/root-equivalence discovery, automatic discovery of arbitrary implicit branches and unrestricted Riemann-surface gluing, boundary-root ownership in native contour routes, non-isolated singular sets and essential singularity isolation remain unresolved. Some supported inputs exhaust bounded effort. Numerical candidates never count as proof. Arbitrary rich elementary inputs have no promised universally terminating solver. Selected multiple-root cases can complete while a narrower simple-root conditional guarantee is inapplicable.

## Property-analysis boundaries

Scalar Piecewise order, curvature and variation include nested branches and owned seams. Monotonic partitions assemble supported Piecewise branches and existing seam certificates, including constant cells, owned singleton values and jumps. A complete partition establishes coverage and cell behavior; it does not imply global monotonicity or derivative critical-point completeness. Separable multivariate curvature can reuse scalar branch conclusions; coupled Piecewise Hessians cannot certify behavior through a seam. Exact symbolic extrema decline intervals with source holes or unproved interior regularity. Membership conditions and equivalent interval restrictions use the same real-set intersection checks.

Monotonic partitions use cached-construction replay. Finite-domain Lipschitz, limiting-gap, seam-continuity, entire-cancellation and finite motion/jump variation proofs have independent replay checkers. Other metric/variation routes retain their own evidence and may have no registered replay proof. Independent root/contour/coverage evidence has a separate contract. Higher-degree algebraic coefficient fields, transcendental parameter geometry, arbitrary analytic common-zero discovery and automatic implicit-branch discovery remain larger capability gaps. See the [parameter geometry tutorial](tutorials/parameter-geometry.md) for the bounded extensions.

## Coefficient routing

The semialg adapter classifies numeric coefficient fields and symbolic parameters before loading its rational-coefficient portfolio. Rational coefficients, including supported rational parameter problems, remain eligible. Up to four exact real algebraic constants in a compositum of degree at most four can use a uniquely isolated rational auxiliary generator for domain, range and sign queries. Rational formulas on one connected interval also admit derivative-based monotonicity/convexity checks. Original source definition guards and input restrictions accompany the generator. Larger algebraic fields, transcendental, nonreal, inexact and unresolved coefficient fields bypass that portfolio and leave the native exact routes available. The classification includes constants in input-domain and target-domain restrictions. Skipping a portfolio does not establish a result: a native method must still prove it. This bounded lift uses rational semialgebraic elimination; it does not provide unrestricted coefficient fields or symbolic coefficient parameters in the lift.
