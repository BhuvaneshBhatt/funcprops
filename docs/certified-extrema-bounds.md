# Univariate optimization

Extrema bounds, finite-component minimization and global-minimum certificates are provided by [symbopt’s univariate optimization interface](https://github.com/BhuvaneshBhatt/symbopt/blob/main/docs/guide/univariate-analysis.md). funcprops supplies source-domain records, derivative-root coverage and outward value enclosures. Install symbopt with its funcprops extra to run the optimization examples.
